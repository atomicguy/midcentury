# midcentury README

## A Theme Inspired by the book Our Friend the Atom

## Editors

- **VS Code**: `themes/Midcentury-color-theme.json` (dark) and `themes/Midcentury-light-color-theme.json` (light) — see `package.json`.
  The light theme is derived from the dark one by `scripts/make_light.py`; rerun it after changing the dark palette.
- **Zed**: `zed/` — a self-contained Zed extension. To try it locally, open Zed's extensions
  page (`zed: extensions` in the command palette), click "Install Dev Extension", and select
  the `zed/` directory.
